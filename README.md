# Binance USDT-M Futures Market Microstructure Data Miner

Sistem berbasis Python Async dengan keandalan tingkat institusi yang dirancang khusus untuk melakukan mining data *market microstructure* secara real-time (resolusi 1 detik) langsung dari bursa Binance Futures USDT-M.

---

## 1. Cara Instalasi & Menjalankan

### Prasyarat
Pastikan environment Anda menggunakan Python versi 3.10 atau yang lebih baru.

### Cara Install Dependencies
Pasang seluruh pustaka yang diperlukan menggunakan perintah berikut:
